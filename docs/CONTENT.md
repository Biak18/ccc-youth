# Content Guidelines

## 1. Content Philosophy

The website should document the real Youth community.

Prefer:

- Real photos
- Real activities
- Real event information
- Real Youth stories
- Clear dates
- Short, readable descriptions

Avoid unnecessary stock imagery when actual Youth photos are available.

---

## 2. Activity Content

Every activity should contain:

- Title
- Description
- Activity date
- Location
- Cover image
- Photos
- Optional videos

Example:

```text
Title:
Youth Camp 2026

Date:
August 15, 2026

Location:
[Location]

Description:
A Youth gathering focused on worship, fellowship,
Bible study and group activities.
```

---

## 3. Photos

Leaders should be able to:

- Upload multiple images.
- Preview images.
- Remove images.
- Reorder images.
- Select a cover image.

Recommended behavior:

```text
Upload
   ↓
Preview
   ↓
Reorder
   ↓
Choose Cover
   ↓
Publish
```

Images should be resized/compressed appropriately before public delivery.

---

## 4. Videos

Leaders should be able to:

- Upload a video where appropriate.
- Add a YouTube URL.
- Add an external video URL.
- Add a thumbnail.
- Add a title.
- Associate the video with an activity.

For large videos, prefer YouTube or another dedicated video host.

---

## 5. Events

Events should contain:

- Title
- Date
- Time
- Location
- Description
- Cover image
- Optional registration link

Upcoming events should be visible prominently on the homepage.

---

## 6. Announcements

Announcements should be short and clear.

Fields:

- Title
- Content
- Optional image
- Publication date
- Pinned status
- Author

Important announcements can be pinned.

---

## 7. Youth Memories

Historical activities should be presented as:

> Youth Memories

Possible organization:

```text
2026
├── Youth Camp
├── Community Service
├── Youth Fellowship
└── Christmas Celebration

2025
├── Youth Conference
└── Youth Retreat
```

This archive should become more valuable as the years pass.

---

## 8. Dates

Always display the actual activity/event date.

Do not replace the activity date with the upload date.

Use consistent formatting:

```text
September 15, 2026
```

For events, also show:

```text
Sunday · 4:00 PM
```

---

## 9. Publishing Workflow

Content states:

```text
Draft → Published → Archived
```

Draft:

- Visible to authorized dashboard users only.

Published:

- Visible on the public website.

Archived:

- Preserved for historical purposes.
- Removed from current/featured sections.

---

## 10. Content Ownership

Leaders should only manage content they are authorized to manage.

Administrators can manage all content.

---

## 11. Social Media

The website should complement Facebook.

Recommended division:

### Website

- Permanent activity archive
- Events
- Structured announcements
- Photo galleries
- Video archive
- Church information

### Facebook

- Frequent updates
- Social engagement
- Short announcements
- Daily/weekly posts
- Community interaction

The website should link clearly to the church's Facebook page.
